DocScan AI 0.3.18 - install

WHAT CHANGED SINCE 0.3.17

  Only speed. 0.3.17 switched off the rule that trimmed a strip off each detected page, and that
  rule was the only thing still using the M-LSD line detector's output - but the detector kept
  running it on every photo for nothing. 0.3.18 skips it.

      median detection, 42 new photos      110 ms  ->   39 ms
      median detection, 116 original ones  125 ms  ->   51 ms

  Output is unchanged: all 158 photos replayed through the real detector show 0 quads changed,
  0 provenance changes and 0 gate changes. Quality scores identical to three decimals.

  If you are on 0.3.16 or older, the accuracy fixes are in 0.3.17 - this release is speed on top.

RELEASE APK  (signed, recommended)
  1. If a DEBUG build is already installed, remove it first:
       adb uninstall com.docscanai
  2. adb install -r DocScanAI-0.3.18.apk
  3. No PC? Copy DocScanAI-0.3.18.apk to the phone and open it from the file manager.

DEBUG APK  (for bug reports; different signing key)
  adb install -r DocScanAI-0.3.18-debug.apk

Both are arm64-v8a. Android 8.0+ (API 26). No Play services needed.
The AI models download in-app on first launch, or are pushed by tooling.

KNOWN LIMITS

  The AI models are a separate in-app download (~35 MB) and are not bundled.
  Detection was measured by replaying photos through the real detector on an emulator, not on a
  physical phone camera.
  Remaining detection failures are the page edge being missed by a few percent, and a printed
  panel inside a page (a white sticker sheet on a book cover) being locked instead of the page.
